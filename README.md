# Sistema de Reserva de Salas – Desenvolvimento Web III (Projeto 09)

Aplicação web desenvolvida para o gerenciamento de reservas de salas de estudo e laboratórios de uma instituição de ensino, implementando CRUD completo, API REST com Node.js puro, interface responsiva e integração com a BrasilAPI.

## 🚀 Tecnologias Utilizadas
- **Node.js** e módulo nativo `http` (sem frameworks)
- **HTML5, CSS3 e JavaScript (Vanilla)** com `fetch()`
- Persistência de dados em arquivo JSON (`db.json`)
- Integração com a **BrasilAPI** para verificação de feriados nacionais

## 📋 Pré-requisitos
Certifique-se de ter o **Node.js** instalado em sua máquina.

## 📥 Instalação e Execução

1. Clone o repositório em sua máquina ou acesse a pasta do projeto.
2. Certifique-se de possuir a estrutura correta contendo o `server.js` e a pasta `public/` com os arquivos estáticos.
3. No terminal, inicie a aplicação:
   ```bash
   node server.js
